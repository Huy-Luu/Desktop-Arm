# Desktop AI Robot Arm Resources

## Knowledge

- [Google DeepMind MuJoCo Documentation](https://mujoco.readthedocs.io/)
  Official documentation for the MuJoCo physics engine. Use for: XML model syntax (MJCF), joint definitions, actuators, sensors, and contacts.
- [Gymnasium Robotics / Farama Foundation](https://robotics.farama.org/)
  Standard reinforcement learning environments for robotics. Use for: observation/action space design and reward shaping.
- [Stable-Baselines3 Documentation (PPO)](https://stable-baselines3.readthedocs.io/en/master/modules/ppo.html)
  Gold-standard PyTorch implementations of reinforcement learning algorithms. Use for: hyperparameter tuning for continuous control.
- [Trinamic TMC2209 Datasheet](https://www.trinamic.com/products/integrated-circuits/details/tmc2209-la/)
  Hardware specification for silent stepper drivers. Use for: UART pinouts, StealthChop2, and StallGuard4 threshold tuning.
- [Google AI Studio / Gemini API Quickstart](https://ai.google.dev/gemini-api/docs)
  Documentation for Gemini 2.0 Flash multimodal vision capabilities. Use for: extracting structured JSON spatial bounding boxes and coordinates from workspace images.
- [Modern Robotics: Mechanics, Planning, and Control (Kevin Lynch / Northwestern)](https://modernrobotics.northwestern.edu/)
  High-trust primary text on robot kinematics. Use for: understanding Forward Kinematics, Inverse Kinematics, and DH parameters.

## Wisdom (Communities)

- [r/robotics](https://reddit.com/r/robotics)
  Active community of roboticists, students, and hobbyists. Use for: actuator selection, gear backlash discussions, and 3D printing tolerances.
- [r/reinforcementlearning](https://reddit.com/r/reinforcementlearning)
  High-signal community for RL practitioners. Use for: reward function debugging and sim-to-real domain randomization tips.
- [MuJoCo GitHub Discussions](https://github.com/google-deepmind/mujoco/discussions)
  Official DeepMind discussion board for MuJoCo physics and MJCF issues. Use for: troubleshooting simulation instabilities and mesh collision questions.
